# TodoApp - iPhone 风格待办事项应用

一个简洁优雅的 iOS 待办事项应用，采用 SwiftUI 开发，支持深色模式和本地数据存储。

## 功能特性

- ✅ **添加待办事项** - 快速添加新的任务
- ✅ **删除待办事项** - 滑动删除或编辑删除
- ✅ **标记完成** - 点击复选框标记任务完成状态
- ✅ **深色模式** - 自动适应系统深色模式
- ✅ **本地数据存储** - 使用 CoreData 持久化数据
- ✅ **优雅的 UI** - iPhone 原生风格设计

## 技术栈

- **SwiftUI** - 现代化 UI 框架
- **CoreData** - 本地数据持久化
- **MVVM** - 架构模式

## 系统要求

- iOS 15.0+
- Xcode 13.0+
- Swift 5.5+

## 使用方法

1. 克隆仓库
```bash
git clone https://github.com/Sunyuanze123/sam1226.git
```

2. 打开项目
```bash
cd sam1226
open TodoApp.xcodeproj
```

3. 在 Xcode 中选择你的目标设备或模拟器，按 `Cmd + R` 运行
